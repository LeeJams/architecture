    04 대체 기술

    무엇을 어떤 기술로 대체할까

    현재 기술을 먼저 고르고, 그 역할을 대체할 기술을 확인하세요. 각 카드에서 교체하는 부분과 기존 구성에 연결할 부분을 구분해 설명합니다.

    현재 기술 → 대체 기술
    제공 회사 · 교체 범위 · 설정 예시

    전달망·HTTP 서버·운영체제·클라우드는 각각의 역할 범위에서 대체를 검토합니다. 구성과 연동을 다시 맞추는 선택이며 Netflix의 실제 교체 계획을 뜻하지 않습니다.

    02

    라이브 스트리밍 처리 순서

    ByteByteGo · 라이브 스트리밍

    참고할 점
    번호, 화살표, 경계로 처리 순서와 담당 영역을 연결합니다. 프로토콜은 연결선에 표시합니다.

    이 사이트에서 참고한 부분
    왼쪽의 재생 단계를 누르면 해당 연결선만 강조하고, 영상 경로는 굵기와 색으로 구분합니다.

    라이브 방송 설명입니다. 주문형 영상인 이번 주제에는 도식의 표현 기법만 참고합니다.

    CDN 거점 분포

    System Design Primer · CDN

    참고할 점
    지리적 분산을 보여줘, 사용자 가까이에 콘텐츠를 둔다는 CDN의 목적을 직관적으로 전달합니다.

    이 사이트에서 참고한 부분

    일반적인 CDN 개념도입니다. 실제 Netflix의 거점 위치를 나타내는 자료는 아닙니다.
